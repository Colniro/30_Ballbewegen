About the Project
-----------------

A small C# Windows Forms project created for practice with graphical desktop applications. 
The application starts through Program.cs and opens the main window with Form1.

Project Goal
------------

The goal of this project was to build a simple WinForms application involving ball movement and to practice working with forms, UI logic, and event-driven programming.

Features
- Desktop application built with Windows Forms.
- Application entry point defined in Program.cs.
- Launches the main form with Application.Run(new Form1()).
- Intended as a small movement-based exercise project.

What I Practiced
----------------

- Creating a GUI application with WinForms.
- Understanding the startup structure of a .NET desktop project.
- Working with forms and project configuration files in Visual Studio.

How To Download
---------------

1. Go to the top right of the project and download the code in a ZIP file
2. Unzip the ZIP file
3. Check that VS 2026 is installed
4. Double-Click the '.slnx' file and wait for it to open VS 2026
5. Start the game by pressing F5 or the start button
